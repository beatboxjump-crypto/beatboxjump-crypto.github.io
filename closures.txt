# 臨時休診のお知らせ(このファイルを編集すると、ホームページに反映されます)
#
# 書き方: 1行に1件。「日付 区分 理由」の順に、スペースで区切ります。
#   日付 ... 2026-11-12 の形(年-月-日)。期間は 2026-12-29〜2027-01-03 のように〜でつなぎます。
#   区分 ... 終日 / 午前 / 午後 のどれか(省略すると終日になります)。
#   理由 ... 自由な文章(省略できます)。
# 行の先頭に # を付けると、その行は無視されます。
# 過ぎた日付は自動で表示されなくなるので、消さなくても大丈夫です。
#
# 例:
#   2026-11-12 終日 院長の学会参加のため
#   2026-11-20 午後 院長都合のため
#   2026-12-29〜2027-01-03 終日 年末年始のため
#
